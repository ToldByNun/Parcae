# Parity goldens (CPU `ParityRecord`, schema `parcae.parity_record.v0`)

Generated by `parcae-parity-gen` (deterministic recipes). Do **not** hand-edit
hash fields; regenerate with the tool instead.

## Files per golden

| File | Contents |
|------|----------|
| `<name>.json` | `ParityRecord` (`backend`: `"cpu"`) |
| `<name>.case.json` | Replay recipe: transform, direction, params, interrupt, idx29 paths |
| `<name>.in.idx29` | Raw input Index29 bytes (`uint8_t`) |
| `<name>.out.idx29` | Raw CPU output Index29 bytes |

`manifest.json` lists all golden names.
