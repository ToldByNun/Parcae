# Spec: Index29 and \(\mathbb{Z}_{29}\) Arithmetic

**Status:** Normative  
**Headers (planned):** `parcae/core/index29.hpp`, `parcae/core/z29.hpp`  
**Research:** [gematria-primus.md](../research/gematria-primus.md)

## Types

### `Index29`

- Represents a Gematria Primus **index** in `{0,1,…,28}`.
- Storage: `std::uint8_t` (or equivalent) with invariant enforced at construction.
- Construction from an integer **MUST** reject any value outside `0..28` (hard
  error / `Status` failure). **MUST NOT** silently clamp or wrap on construction
  from an untrusted integer.
- Arithmetic wrap is performed only by explicit \(\mathbb{Z}_{29}\) operations.

### Domain constant

```text
MODULUS = 29
```

Primes attached to the alphabet are **not** the modulus. See research profile.

## Operations (decrypt/encrypt building blocks)

All of the following **MUST** be pure, `constexpr`-friendly where practical, and
side-effect free.

| Op | Definition | Notes |
|----|------------|-------|
| `add(x, y)` | `(x + y) mod 29` | Inputs already in `0..28` |
| `sub(x, y)` | `(x - y) mod 29` | Equivalent to `add(x, neg(y))` |
| `neg(x)` | `(29 - x) mod 29` | `neg(0) = 0` |
| `mul(x, y)` | `(x * y) mod 29` | |
| `inv(a)` | unique `a⁻¹` with `mul(a, a⁻¹) = 1` | Defined for `a ∈ 1..28` only |
| `atbash(x)` | `sub(28, x)` i.e. `28 - x` | Involution: `atbash∘atbash = id` |

### Modular inverse

Because 29 is prime, every `a ∈ 1..28` has an inverse. A conforming
implementation **MUST**:

- Reject `inv(0)`
- Satisfy `mul(a, inv(a)) == 1` for all `a ∈ 1..28`
- Prefer a precomputed table of size 28 or Fermat `a^(27) mod 29` — either is fine
  if tested

### Affine maps

Encrypt: `c = add(mul(a, p), b)` with `a ∈ 1..28`, `b ∈ 0..28`  
Decrypt: `p = mul(inv(a), sub(c, b))`

Caesar decrypt with shift `b`: `p = sub(c, b)` (`a = 1`).  
Atbash is the dedicated map above (implementations **MAY** also express it as an
affine special case, but tests **MUST** cover `atbash` as a named op).

## Error policy

| Situation | Behavior |
|-----------|----------|
| Build `Index29` from out-of-range | Hard error |
| `inv(0)` | Hard error |
| Span element already validated as `Index29` | Ops assume invariant; debug asserts allowed |

## Test vectors (normative samples)

| Expression | Result |
|------------|--------|
| `add(28, 1)` | `0` |
| `sub(0, 1)` | `28` |
| `atbash(0)` | `28` |
| `atbash(28)` | `0` |
| `atbash(atbash(x))` | `x` for all `x` |
| `mul(2, inv(2))` | `1` |
| `mul(15, inv(15))` | `1` |

Implementations **MUST** include exhaustive tests for `inv` on `1..28` and
involution of `atbash` on all 29 values.

## Serialization

- JSON / manifests: integer `0..28`
- Binary buffers for parity: `uint8_t` per index, tightly packed
- Invalid serialized values **MUST** fail load — never wrap on parse
